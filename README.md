# From-scratch

This repository is meant to archive my progress of writing things from scratch.

Before coding anything, I study the theory on paper.

Then, I study implementations online. And I write my own version, to test my understanding.

For the sake of gamification, I time my writeups. As soon as i need to check anything online, I pause the timer and stop the attempt.

Between attempts, I may write certain functions on their own to build an understanding, but the entire writeup is timed end to end.
